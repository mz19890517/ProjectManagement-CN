# 项目管理（C# 移植版）

原易语言程序 `项目3.1.e`（项目管理 v3.1，作者 孟国胜）的 C# WinForms 移植版。
解包工具：[e-packager v1.2.25](https://github.com/aiqinxuancai/e-packager)（源码已解包为可读文本）。

## 运行 / 发布

```powershell
# 构建（.NET SDK 9 已装）
dotnet build .\src\ProjectManagement\项目管理.csproj -c Release

# 生成独立单文件 exe（目标机不需要装 .NET）
dotnet publish .\src\ProjectManagement\项目管理.csproj -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

Debug 产物：`src\ProjectManagement\bin\Debug\net9.0-windows\项目管理.exe`

## 功能与原版一致

- 项目文件夹命名：`序号—项目名称—归属—生产编号—系统—进度`（“—”＝全角破折号），总目录＝exe 所在目录
- 13 列表格视图：序号 / 项目名称 / 归属 / 生产编号 / 系统 / 报告 / 配置单 / 柜间线 / 线统计 / 布局存档 / 配置文件 / 备注 / 进度
- 检测关键字（文件名或一级子目录名包含即“有”：质检报告、配置单、柜间线、柜间线统计、布局存档、配置文件；“柜间线统计”命中时“柜间线”也置“有”——沿用原判定）
- 着色：进度＝完成 → 整行嫩绿；完成行“无”→ 灰底；未完成行“无”→ 红底
- 右键菜单：新建项目 / 打开项目文件夹 / 更改项目 / 创建质检报告·柜间线统计·合格证·系统配置文件·备注模板 / 标记进度
- 列表行双击或菜单打开项目文件夹
- 新建项目校验序号/项目名称/生产编号重复或空、归属/系统空
- 顶部滑块条（28–100）调整行高；窗口拉伸时列宽按原比例（910 为基准）缩放
- 内置 14 个模板（质检.xls×5、合格证.lsf×5、柜间线统计.xlsx、备注.xlsm、通和.xlsx、正智.rar），单实例互斥启动

## 新增功能（原易语言版没有）

- **设置**：顶部“设置”按钮或右键菜单可指定项目目录（原版只能在 exe 所在目录运行）。
  已保存到 `settings.json`，优先 exe 同目录，不可写时回退 `%LOCALAPPDATA%\项目管理\`；
  留空恢复为程序所在目录；目录不存在时可选创建。
- **编辑模式**：设置对话框里的列编辑器，对中间的检测列（列头）可添加 / 删除 / 改名 /
  修改关联关键字（多个关键字用逗号分隔）/ 上下移动列顺序。
  规则：项目文件夹里的文件或一级子目录名包含该列任一关键字（不区分大小写）→ 该列记“有”。
  `settings.json` 的 `检测列` 即列定义；留空关键字的列保持空白单元格。
  前 5 列（序号—项目名称—归属—生产编号—系统）与最后的“进度”列由
  文件夹命名规则 `序号—项目名称—归属—生产编号—系统—进度` 决定，不在编辑范围。
- **定制右键菜单**：设置 → 定制右键菜单，可添加/删除/排序右键菜单项。
  每个菜单项 = 名称 + 模板文件 + 目标文件（留空同名复制），
  点击后把模板文件复制到选定项目文件夹。
  模板文件格子在编辑器里右键即可选取「模板」文件夹里的文件（或“浏览其他文件…”选全盘文件；
  选在文件夹内的自动记为相对名），选完会提示可用占位符。
  占位符：`{序号} {项目名称} {归属} {生产编号} {系统} {进度}`（模板文件名与目标文件名均可使用）。
  模板文件相对名默认位于 exe 旁「模板」文件夹（编辑器中“导出内置模板…”可把 14 个内置模板导出为可编辑文件再修改）。
  **压缩项也可定制**：模板文件是 .rar/.zip/.7z 时点击菜单会提示“是否解压到项目文件夹”
  （目标文件一栏此时视为解压目录名，留空 = 解压到项目根目录），
  例如默认项“创建对应系统配置文件模板”= 正智配置文件模板.rar → 解压到 `{项目名称}配置 文件`；
  “创建通和配置文件模板”= 通和配置文件模板.xlsx → 复制为 `{项目名称}配置 文件.xlsx`。
- 原“读取项目”旁的行高滑块条已按需求移除（固定行高 28）。
- **新建项目预填**：序号默认填当前列表最大数字序号 +1；归属/系统为下拉框
  （可输入也可选）。预设来源：归属 = 「模板」文件夹一级子文件夹名（**手动创建即预设**）∪ 当前项目中出现过的归属；系统 = 当前项目中出现过的系统（更改项目窗口同）。
- **菜单项可关联文件夹**：模板文件一栏填「模板」文件夹下的子文件夹名（编辑器右键里也会列出子文件夹）。
  点击该菜单项时弹出该文件夹下的文件列表，选中（双击或确定）后创建到当前项目。
- **筛选与排序**：顶部“筛选”框输入即实时过滤（匹配任一列内容，不分大小写）；
  点列头按列排序（同列再点切换升/降序，列头显示箭头），
  启动默认序号列**降序**；筛选/排序在“读取项目”后仍保持。
- **选中高亮**：选中行显示淡蓝底色，红/绿/白行选中均清晰可辨。

## 移植实现对照

| 原易语言实现 | C# 实现 |
|---|---|
| 超级列表框+iext 扩展 | DataGridView（整行选择/表格线/行高/单元格颜色原生支持） |
| 精易模块（文件枚举、目录改名、ANSI/Unicode 转码等） | System.IO 原生 API |
| SkinSharp 皮肤（加载皮肤） | 略（未引入皮肤库） |
| 精易 rar_解压（正智配置文件） | SharpCompress（NuGet）+ 7-Zip/WinRAR 命令行回退 |

## 修复的原版 Bug 与行为改进

1. 启动即自动读取项目列表（原版首次进入列表是空的，需手动点“读取项目”）
2. 列表按名称正序显示（原版枚举后倒序插入，显示为倒序）
3. “无”单元格红/灰底色与检测列对齐（原版着色列比检测列整体偏移一列）
4. 新建项目先校验后一次性建目录（原版把建目录写在校验循环里，会反复建目录）
5. 对话框改为模态（原版非模态，弹窗期间切换选择会把别的项目目录改错名）
6. 删除遗留调试弹窗（每次改名弹出的老项目目录信息框）和死菜单项（原版菜单里 5 个隐藏的“修改××”项不可见不可用）
7. 标记进度：取消输入或输入为空时不再执行改名（原版会用空进度强行改名导致失败弹窗）
8. “配置 文件”（含空格的目录/文件）也算命中“配置文件”列（原版匹配不到，该列恒为“无”）
9. 通和/系统侧“修改生产编号/所属系统”类重复校验错列的问题随死菜单一并移除；更改项目对话框的目录改名仍由文件系统兜底防重名

## 保留的原版命名细节

模板输出文件名与原版完全一致（含空格）：`易能质检 报告.xls`、`易能合格 证.lsf`、`柜间线统 计表.xlsx`、`备 注.xlsm`、`<项目名称>配置 文件\` 等——保证和现有项目数据/工作流程兼容。
